# Level 1 - Task 1: EDA on Retail Sales Data

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Retail Sales dataset.

The objective is to understand the dataset, identify patterns and trends, and generate meaningful insights using Python.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Files

- `Retail_Sales.csv` - Dataset used for the analysis
- `Retail_Sales_EDA.ipynb` - Jupyter Notebook containing the complete EDA

## 🔍 Analysis Performed

- Data loading and understanding
- Data cleaning
- Checking missing values
- Checking duplicate records
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Data visualization
- Identifying trends and patterns
- Generating business insights

## 📊 Key Insights

The analysis was performed to identify important patterns and trends in retail sales data through statistical analysis and visualizations.

## 🎯 Objective

The main objective of this task is to practice Exploratory Data Analysis and understand how data can be transformed into meaningful insights.
