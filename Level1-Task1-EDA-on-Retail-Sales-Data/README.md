# Level 1 - Task 1: EDA on Retail Sales Data

## 📌 Project Overview

This project is part of the Oasis Infobyte Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on a Retail Sales dataset using Python. The analysis focuses on understanding the structure of the data, cleaning the dataset, exploring important variables, identifying patterns and trends, and presenting the findings through meaningful visualizations.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand the structure and characteristics of the Retail Sales dataset.
- Inspect the dataset for missing and duplicate values.
- Perform data cleaning and preprocessing.
- Generate descriptive statistics.
- Analyze individual variables and their distributions.
- Explore relationships between different variables.
- Identify trends and patterns in retail sales.
- Create meaningful visualizations.
- Extract useful insights from the data.

---

## 📂 Dataset

The project uses a Retail Sales dataset containing information related to retail transactions.

## 🔄 Data Analysis Workflow

### 1. Data Loading

The Retail Sales dataset was imported into the Jupyter Notebook using Pandas.

### 2. Dataset Understanding

The dataset was initially explored using:

- `head()`
- `tail()`
- `shape`
- `info()`
- `describe()`
- `columns`

These functions helped understand the structure and characteristics of the dataset.

### 3. Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent values

Necessary preprocessing was performed before further analysis.

### 4. Descriptive Statistics

Descriptive statistics were calculated to understand the numerical variables.

The analysis included:

- Mean
- Minimum
- Maximum
- Standard deviation
- Quartiles

### 5. Exploratory Data Analysis

Different variables were explored individually and in relation to other variables.

The analysis included:

- Distribution analysis
- Category-wise analysis
- Sales-related comparisons
- Relationship analysis
- Trend identification
- Outlier identification
